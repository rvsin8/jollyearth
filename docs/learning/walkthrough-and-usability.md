# Walkthrough and learner usability script

This is a documented journey and test script, **not participant findings or a browser recording**.

## Complete journey

1. Tools → Learning challenges → Habitat Detective. Choose “It is looking for food”; read why a photograph cannot establish intention. Change to “A black cap on its head.” Expand the archival photograph if desired.
2. Explain the visible evidence in your own words. Move to the rail photograph, identify parallel rails, and distinguish an observation from assumptions about passengers or sound. Complete the practice and discuss the reasoning with a partner/teacher. Save reflection to the journal and save that observation.
3. Start a new journal entry to clear the import destination without deleting saved work. Open Rain Lab. Choose Heavy rainfall and Pavement. Predict the garden's effect and explain the prediction. Run. Change only the ground to Add a rain garden. Notice that the old result is marked stale. Run again and compare. Write a reflection; save to journal, then Save observation.
4. Reload journal; reopen the entry, edit, save. Open the example without overwriting the draft. Try Change image and recheck the written evidence. Delete the saved entry with confirmation.
5. Jersey City → Map → Layers. Toggle Waterfront, choose Liberty State Park with the feature selector, press Done. Open the timeline and each dated/planned stage. Browser Back and the map link return with selected park/layers/zoom retained within the session.

## Participant prompts (15–20 minutes)

- “Show me something you can observe in this photo. What would need more evidence?” Avoid revealing the correct answer.
- “How could you test whether changing the ground affects runoff? What must stay the same?”
- “Tell me which result belongs to your prediction and which came from the teaching model.”
- “Save what you learned. Leave, return and make a correction. Where is your work stored?”
- “Find Liberty State Park, change a map layer, and explain which timeline image shows the past and which shows a plan.”

Observe navigation choices, hesitation, keyboard/touch reachability, confusion about attribution, false certainty about flood predictions, and whether the participant can explain evidence in a new case. Do not infer mastery from clicking a correct choice or filling a field. Record verbatim observations and task outcomes separately from facilitator interpretation. Do not collect student names or identifying photos.

No participants were recruited or tested in this implementation session.
