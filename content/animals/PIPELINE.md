# Animal model authoring

The current workflow is documented in [pipeline/README.md](../../pipeline/README.md).

Supply a purchased or externally authored rigged model. Earthbound does not invoke Scenario or generate organism geometry. The private authoring registry is `content/animals/registry.json`; do not edit compiled public JSON. Fidelity review notes remain private. The old v20 export/inspection scripts are retained only for historical compatibility; use the v21 normalize, optimize and validate commands for new deliveries.
